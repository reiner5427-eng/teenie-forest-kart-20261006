# 티니핑 숲속 카트

첨부된 여섯 친구를 직접 제작한 입체 메시로 표현한 한국어 3D 웹 카트 게임입니다. 기존 작업과 분리된 새 프로젝트입니다.

- GitHub: https://github.com/reiner5427-eng/teenie-forest-kart-20261006 (비공개 저장소)
- Netlify: https://teenie-forest-kart-20261006.netlify.app (배포 검증 상태는 VALIDATION.md 참고)
- 코스: 숲속 클로버 서킷, 약 947m, 3랩, 순차 체크포인트 12개

## 실행

Node.js 22 이상과 npm을 설치한 뒤 프로젝트 폴더에서:

```sh
npm install
npm run dev
```

터미널의 로컬 주소를 엽니다. `index.html`을 파일로 직접 열면 브라우저의 ES 모듈 보안 제한과 `/src/` 경로 때문에 실행되지 않습니다.

```sh
npm test
npm run build
npm run preview
```

온라인까지 로컬에서 실행하려면 `npx netlify-cli@23.15.1 dev`를 사용합니다. Windows에서 심볼릭 링크 권한 오류가 나면 일반 로컬 실행으로 오프라인 경기를 확인하고 온라인은 Netlify 배포를 이용하세요. 본 작업 환경의 로컬 Netlify 에뮬레이터는 해당 오류와 Edge 런타임 다운로드 오류로 실행되지 않았습니다.

## 기능

- 하츄핑·아자핑·차차핑·바로핑·라라핑·해핑 입체 모델, 회전 미리보기 및 카트 탑승.
- 스피드전과 아이템전, 플레이어 1명과 경로·커브 감속·드리프트·추월·아이템 규칙을 공유하는 AI 5명.
- 시간 기반 물리, 경사 트랙, 벽·카트 접촉, 차체 방향과 진행 방향이 다른 드리프트, 연기 대신 스파크, 유효한 드리프트의 게이지 충전과 최대 3개 부스터.
- 미사일(추적 발사 뒤 1.8초 방해), 물폭탄(전방 30m, 반경 22m, 2.4초 방해), 바나나(18초 설치, 접촉 시 미끄러짐), 자석(전방 상대가 있으면 2.5초 가속), 실드(4초, 피해 우선 차단).
- 12개 순차 구간을 모두 통과해야 랩 인정. 복귀는 진행도를 변경하지 않습니다.
- HUD 순위·랩·각종 시간·속도·부스터·아이템·미니맵, 결과와 5초 기록 강조.
- `localStorage`의 이 기기 명예의 전당, 모드별 최고 랩 정렬. 정상 3랩 완주만 저장. 온라인 결과는 제외.
- Netlify 전용 온라인 1:1: 6자리 충돌 검사 코드, 참가 토큰 인증, 정확히 2명, 준비·공통 카운트다운, 서버 입력 시뮬레이션, 서버 아이템 소유권·공격·완주 판정, 위치 보간, 15초 이탈 시 기권.

## Netlify 전용 온라인의 한계와 비용

온라인은 WebSocket 서비스가 아닙니다. Functions 요청이 들어올 때 권위 있는 공통 물리 상태를 진행시키고, Blobs의 강한 일관성 읽기와 ETag 조건부 쓰기로 동시 변경을 직렬화합니다. 브라우저가 보낸 위치·랩·완주 시간은 사용하지 않습니다. 참가자의 입력과 서버 시간만 처리합니다. 대기실은 1.5초, 경기는 약 400ms 간격이며 이전 요청이 끝나기 전 다음 요청을 보내지 않습니다. 서버 응답이 느리면 실제 갱신 간격도 늘어납니다. 화면은 보간하지만 조작 지연 자체를 없애지는 못합니다. 빠른 경쟁용 실시간 서비스와 같은 반응 속도를 보장하지 않습니다.

서버는 60Hz의 작은 고정 스텝으로 지난 시간을 최대 1.6초 진행합니다. 긴 정체 후 모든 시간을 한 번에 처리하지 않아 부하가 줄지만, 그 동안 경기가 느려질 수 있습니다. 마지막 입력이 1.2초 이상 오래되면 해제합니다. 상대 요청이 15초 끊기거나 방을 나가면 기권, 남은 참가자가 승리하며 미완주 시간은 `—`로 표시합니다. 방은 45분 뒤 만료되며 오래된 방은 일일 정리 함수에서 삭제합니다.

이론적으로 두 사람이 계속 달리면 400ms 폴링은 분당 약 300회, 한 시간에 약 18,000회의 Function 요청입니다. 재시도에 따른 추가 Blobs 읽기·쓰기가 있을 수 있습니다. 요청·컴퓨트·트래픽과 배포가 계정 사용량에 반영됩니다. 2026-10-06 확인한 새 크레딧 요금제 문서에는 웹 요청 10,000회당 2크레딧이 명시되어 있으므로 1시간의 요청 부분만 약 3.6크레딧입니다. 컴퓨트·대역폭·배포는 별도입니다. 실제 연결 계정의 플랜·잔여량을 Netlify 대시보드에서 확인해야 합니다. 유료 업그레이드나 결제는 수행하지 않았습니다.

공식 문서:
- https://docs.netlify.com/build/functions/overview/ (지속 WebSocket 서버가 아닌 요청 기반 Functions)
- https://docs.netlify.com/build/functions/optional-configuration/ (동기 Function 실행 제한)
- https://docs.netlify.com/build/data-and-storage/netlify-blobs/ (`strong`, `onlyIfNew`, `onlyIfMatch`, `modified`)
- https://docs.netlify.com/manage/accounts-and-billing/billing/billing-for-credit-based-plans/how-credits-work/

## 배포와 비밀 정보

`netlify.toml`의 빌드 명령은 `npm run build`, 공개 디렉터리는 `dist`, 함수 디렉터리는 `netlify/functions`입니다. GitHub 저장소의 `main`을 전용 Netlify 프로젝트에 연결합니다. Blobs 인증은 Netlify Functions 런타임에서 자동 제공되므로 별도 외부 서비스나 브라우저 비밀키는 필요하지 않습니다. `.env.example`에는 필요한 설정 여부를 기록했습니다.

CLI를 사용할 경우 기존 사이트를 선택하지 말고 본 프로젝트 ID `decae0ea-2980-4ab5-938f-d0a44f3a2626`로 연결합니다:

```sh
npx netlify-cli@23.15.1 login
npx netlify-cli@23.15.1 link --id decae0ea-2980-4ab5-938f-d0a44f3a2626
npx netlify-cli@23.15.1 deploy --prod --build
```

## 파일 안내

- `src/models.js`: 직접 만든 6종 캐릭터·카트 메시
- `src/sim.js`: 클라이언트·서버 공통 경로·주행·순위·아이템 규칙
- `src/scene.js`: 숲과 트랙 렌더링·추적 카메라
- `src/main.js`: 메뉴·조작·HUD·명예의 전당·온라인 UI
- `netlify/functions/_shared/rooms.js`: 방 인증·원자적 상태 갱신·서버 시뮬레이션
- `tests/`: 주행과 온라인 상태 규칙 테스트
- `src/qa.js`: `npm run dev`의 `?qa` 개발 검증 버튼. 프로덕션 빌드에는 포함되지 않습니다. 자동 주행 검증은 실제 사용자 조작을 대체하지 않고 같은 물리 규칙과 UI의 완주·기록 저장을 확인하는 개발 도구입니다.

참고 자산·원작과의 차이는 ASSETS.md, 실제 확인한 범위는 VALIDATION.md에 기록합니다.
